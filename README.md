# Readback — support and policies

Readback is an app for Jira and Confluence Cloud, built on Atlassian Forge by Readback Labs. When a procedure changes, it finds the work and the people it governs, collects a read-back, and holds the Jira transition until the assignee has read the revision that is in effect.

- **Privacy policy**: [PRIVACY.md](PRIVACY.md)
- **Support**: open an issue in this repository: https://github.com/onipam78/readback-docs/issues

Please do not include personal data or confidential content from your site in an issue.
